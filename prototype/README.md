# 리디 → 옵시디언 프로토타입

한 권의 독서노트를 가져와 기존 Markdown에 추가하는 시험용 도구입니다. 외부 서버로 데이터를 보내지 않습니다. 원본 파일을 수정하지 않고 새 Markdown 파일을 내려받습니다.

## 1. 브라우저 확장 설치

Chromium 계열 브라우저의 확장 관리 화면에서 개발자 모드를 켜고, ‘압축해제된 확장 프로그램 로드’를 선택해 `extension` 폴더를 지정합니다. Dia에서 이 기능이 제공되지 않으면 Chrome에서 설치하고 리디에 로그인해야 합니다. 확장 프로그램은 해당 버튼을 누른 현재 탭에만 접근합니다.

## 2. 리디에서 수집

1. 리디 독서노트에서 책을 선택합니다.
2. 필터를 ‘전체’로 두고, 화면 아래 ‘더보기’를 없어질 때까지 누릅니다.
3. 확장 프로그램 버튼을 누르고 ‘이 책의 노트 내보내기’를 누릅니다.
4. JSON 파일이 다운로드됩니다. 전체 개수와 수집 개수가 다르면 저장하지 않습니다.

## 3. Markdown에 반영

1. `import.html`을 브라우저에서 엽니다.
2. 위 JSON 파일과 기존 옵시디언 책 노트의 Markdown 파일을 선택합니다.
3. 미리보기를 확인하고 결과 파일을 다운로드합니다.
4. 결과를 직접 확인한 후 옵시디언의 원본과 교체하거나 필요한 부분을 복사합니다.

## 범위와 한계

- 한 번에 한 권만 처리합니다. 책과 파일의 연결은 사용자가 선택합니다.
- 노트 ID를 기준으로 새 항목만 추가합니다. 리디에서 수정·삭제한 기존 항목은 자동 변경하지 않습니다.
- 노트의 `독서노트` 제목이 없으면 파일 끝에 만듭니다. 같은 제목이 여러 개면 처리를 중단합니다.
- 자동 관리 영역의 표시가 손상되거나 같은 ID가 중복되면 처리를 중단합니다.
- 리디의 화면 구조가 바뀌면 수집이 실패할 수 있습니다. 이 버전은 웹 화면 구조를 이용합니다.
- 실제 계정 데이터로 확장 프로그램을 설치하거나 파일을 저장하는 전체 흐름은 아직 시험하지 않았습니다.
