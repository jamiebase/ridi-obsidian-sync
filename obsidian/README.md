# 옵시디언 연결 프로토타입

`main.js`와 `manifest.json`을 보관함의 플러그인 폴더에 복사하고 플러그인을 다시 켭니다. 브라우저 확장도 확장 관리 화면에서 새로고침합니다.

1. 대상 책 노트를 옵시디언에서 엽니다.
2. 명령어 팔레트에서 `리디 확장 프로그램에서 가져오기`를 실행합니다.
3. 연결 코드를 복사합니다. 코드는 2분 동안 유효합니다.
4. 리디 책별 독서노트를 모두 펼치고 확장 프로그램을 엽니다.
5. 코드를 붙여 넣고 `옵시디언으로 보내기`를 누릅니다.
6. 옵시디언 미리보기에서 책 제목과 대상 노트를 확인하고 반영합니다.

연결은 127.0.0.1에만 열리고, 일회성 코드를 사용하며 전송 후 닫힙니다. 파일에 저장한 JSON을 가져오는 기존 명령도 사용할 수 있습니다. 중복 ID는 건너뛰고 리디에서 수정하거나 삭제한 기존 항목은 반영하지 않습니다. 저장 전에 노트가 바뀌면 쓰기를 중단합니다. 실제 확장과 옵시디언 사이의 연동은 아직 검증하지 않았습니다.
