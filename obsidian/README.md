# 옵시디언 플러그인 프로토타입

## 설치

1. 옵시디언 보관함의 설정 폴더(보통 `.obsidian`) 안 `plugins/ridi-obsidian-sync/` 폴더를 만듭니다.
2. 이 폴더의 `main.js`와 `manifest.json`을 그 안으로 복사합니다.
3. 옵시디언 설정 → 커뮤니티 플러그인에서 새로고침하고 `Ridi Obsidian Sync`를 활성화합니다.

## 사용

1. 대상 책 노트를 옵시디언에서 엽니다.
2. 명령어 팔레트에서 `리디 독서노트 JSON 가져오기`를 실행합니다.
3. 브라우저 확장에서 저장한 JSON을 선택합니다.
4. 리디 책 이름, 대상 경로, 전체 미리보기를 확인하고 `노트에 반영`을 누릅니다.

같은 ID는 다시 추가하지 않습니다. 기존 항목의 리디 측 수정과 삭제는 반영하지 않습니다. 노트가 미리보기 이후 바뀌면 저장을 중지합니다. 책 연결은 현재 열려 있는 노트로 직접 지정합니다. 실제 리디와 옵시디언에서의 전체 흐름은 아직 시험하지 않았습니다.
