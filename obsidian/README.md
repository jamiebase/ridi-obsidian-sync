# 옵시디언 연결 프로토타입

`main.js`와 `manifest.json`을 보관함의 플러그인 폴더에 복사하고 플러그인을 다시 켭니다. 브라우저 확장도 확장 관리 화면에서 새로고침합니다.

1. 대상 책 노트를 옵시디언에서 엽니다.
2. 명령어 팔레트에서 `리디 확장 프로그램에서 가져오기`를 실행합니다.
3. 연결 코드를 복사합니다. 코드는 2분 동안 유효합니다.
4. 리디 책별 독서노트를 모두 펼치고 확장 프로그램을 엽니다.
5. 코드를 붙여 넣고 `옵시디언으로 보내기`를 누릅니다.
6. 옵시디언 미리보기에서 책 제목과 대상 노트를 확인하고 반영합니다.

연결은 127.0.0.1에만 열리고, 일회성 코드를 사용하며 전송 후 닫힙니다. 파일에 저장한 JSON을 가져오는 기존 명령도 사용할 수 있습니다. 중복 ID는 건너뛰고 리디에서 수정하거나 삭제한 기존 항목은 반영하지 않습니다. 저장 전에 노트가 바뀌면 쓰기를 중단합니다. 실제 확장과 옵시디언 사이의 연동은 아직 검증하지 않았습니다.

## 연결 코드 기억하기 (0.3)

옵시디언 명령으로 연결을 시작하고 브라우저 확장에서 처음 한 번 코드를 입력해 전송하면, 이후 확장이 코드를 자동으로 채웁니다. 옵시디언과 브라우저 확장 두 곳에 연결 코드가 저장됩니다. 옵시디언 설정 폴더가 다른 기기와 동기화되면 코드도 함께 동기화될 수 있습니다. 연결은 매번 옵시디언에서 명령을 실행한 후에만 2분간 열립니다. 고정 포트 43177이 사용 중이면 연결이 실패합니다. 아직 옵시디언 한 번 클릭만으로 수집되지는 않으며, 확장의 보내기 버튼을 눌러야 합니다.

## 현재 책 자동 가져오기 (0.4)

확장 프로그램과 플러그인을 갱신합니다. 확장의 사이트 접근 권한이 추가되므로 다시 활성화해야 할 수 있습니다. 확장이 설치된 브라우저를 기본 브라우저로 설정합니다. 최초 한 번은 이전 방식으로 연결 코드를 입력하고, 해당 책 노트에 독서노트를 한 번 가져와야 합니다.

대상 노트를 열고 명령어 팔레트에서 `현재 책의 리디 독서노트 자동 가져오기`를 실행하면 리디 책 페이지가 기본 브라우저에서 열립니다. 확장은 해당 페이지의 더보기를 반복하여 전체 노트를 수집하고 옵시디언에 전달합니다. 옵시디언의 미리보기를 확인한 뒤 반영합니다. 노트에 책 ID가 없거나 여러 개면 중단합니다. 리디 로그인이 만료되었거나 확장이 기본 브라우저에 설치되지 않으면 수집할 수 없습니다. 기존 코드 입력 방식은 계속 사용할 수 있습니다.

이 기능은 리디 사이트의 화면 구조에 의존합니다. 권한은 확장이 리디 페이지의 내용을 읽고 수집하는 데 사용합니다. 브라우저 확장과 옵시디언을 갱신한 뒤의 실제 통합 시험은 아직 수행하지 않았습니다.

## 책 ID 속성

처음 가져오기 결과를 확인하고 반영하면 노트의 frontmatter에 텍스트 속성 `ridi_book_id`를 저장합니다. 새 밑줄이 없어도 속성을 추가할 수 있습니다. 자동 가져오기는 이 속성을 우선 사용하며, 속성이 없는 기존 노트는 밑줄의 ID를 사용합니다. 속성, 기존 밑줄, 가져온 책의 ID가 일치하지 않으면 중단합니다. 여러 리디 책의 밑줄이 한 노트에 섞여 있어도 중단합니다. 속성 저장은 밑줄 반영 후 별도로 진행하므로 속성 저장에 실패하면 메시지를 확인하고 다시 실행하세요.

## 연결된 여러 책 가져오기

옵시디언에서 `연결된 모든 책의 리디 독서노트 가져오기` 명령을 실행합니다. `ridi_book_id` 속성이 있는 Markdown 노트만 대상으로, 브라우저에서 리디 책 페이지를 한 권씩 열어 수집합니다. 책별 미리보기와 건너뛴 이유를 확인한 뒤 반영 버튼을 누릅니다. 같은 책 ID를 가진 노트가 여러 개이거나, 속성과 기존 밑줄 ID가 충돌하면 해당 노트들을 건너뜁니다. 파일이 미리보기 이후 바뀌면 그 파일은 저장하지 않습니다. 반영은 파일별로 실행하므로 일부만 성공할 수 있으며, 실패 내역을 화면에 표시합니다. 다시 실행해도 이미 저장된 밑줄은 중복하지 않습니다.

수집을 취소하면 현재 연결을 닫고 아직 수집하지 않은 책을 건너뜁니다. 각 책은 최대 약 44초 동안 기다립니다. 확장 프로그램을 기본 브라우저에 설치하고 연결 코드를 처음 한 번 저장해야 합니다. 책마다 브라우저 탭이 열립니다. 로컬 파일은 미리보기에서 반영을 누르기 전까지 수정하지 않습니다.

개발 시 `node obsidian/build.js`로 `main.js`를 생성하고, `node obsidian/build.js --check`로 원본과의 일치를 확인합니다.

## 리디 책장에서 선택해 가져오기

갱신한 플러그인과 브라우저 확장이 필요합니다. 확장이 설치된 브라우저를 기본 브라우저로 지정하세요. 보관함을 처음 등록할 때는 옵시디언에서 아무 노트나 열고 `리디 확장 프로그램에서 가져오기` 명령을 실행합니다. 연결 창을 열어 둔 채 리디의 `독서노트 책장`에서 확장을 열고, 연결 코드를 입력한 다음 `열린 보관함 연결`을 누릅니다. 기존에 저장한 코드가 있으면 그대로 사용합니다. 연결한 보관함은 이후 목록에서 선택할 수 있습니다. 책을 개별 선택하거나 전체 선택하고, 옵시디언으로 보내는 링크를 누릅니다. 운영체제의 앱 열기 확인이 나타나면 옵시디언을 여세요. 표시된 보관함을 확인한 뒤 `수집 시작`을 누릅니다.

`ridi_book_id`가 일치하는 노트는 기존 위치에 반영합니다. 연결된 노트가 없는 책은 수집한 제목으로 보관함 최상위에 Markdown을 만듭니다. 금지된 파일명 문자는 `-`로 바꿉니다. 같은 ID가 여러 노트에 있거나, 같은 이름의 파일·폴더가 있는 책은 건너뜁니다. 모든 결과를 미리 보여주며 반영 버튼을 누르기 전에는 노트를 변경하지 않습니다. 신규 파일의 경합은 파일 생성 직전에 다시 검사합니다. 파일별 반영이므로 일부만 성공할 수 있습니다.

책장 검색어를 지워야 하며, 목록의 표시 개수가 리디의 전체 개수와 다르면 수집을 중단합니다. 현재 한 번에 최대 300권을 선택할 수 있습니다. 리디의 UI 구조 변경이나 브라우저의 외부 앱 열기 설정에 따라 사용 흐름이 달라질 수 있습니다. 선택한 책 ID와 보관함 이름을 옵시디언 URI로 전달합니다.
